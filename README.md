# 버츄얼 연결 — 기능 검증 프로토타입

국내 방송인·제작자·시청자를 연결하는 탐색 UI입니다. 모든 프로필과 작업은 가상 예제이며 실제 의뢰·방송·등록을 받지 않습니다.

## 구현

- 방송인/제작자/저장한 프로필 탐색
- 플랫폼·콘텐츠 필터, 선호 분위기 정렬
- 프로필→작업→제작자 양방향 연결
- 브라우저 즐겨찾기, 입문 경로와 공식 학습 링크
- 공개/미공개 관계 필터 테스트

## 실행·테스트

`python -m http.server 8000`, `npm test` (Node 내장 러너)

## 아직 구현하지 않은 기능

실제 DB·본인 확인·신청 접수·관리자 승인·정정·스팸 제한·실존 인물 데이터·회원 기능. 신규 DB 접근과 초기 참여 검증 전에는 이 프로토타입을 실제 플랫폼으로 운영하지 않습니다. 가짜 접수·가짜 인증을 보여주지 않습니다. 중앙 실행계획 E02 개발 게이트에 따라 본개발은 보류합니다.

Vercel 상업 운영 플랜 전환 및 실제 참여자 확보는 미완료입니다.
