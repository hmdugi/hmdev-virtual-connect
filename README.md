# 버츄얼 연결

국내 방송인·제작자·시청자를 잇는 탐색과 참여 신청 MVP입니다. 기존 탐색 데모에 서버 신청·승인 흐름을 추가했습니다. **실제 인증·DB·상업 배포는 아직 연결하지 않았습니다.**

## 구현

- 방송인/제작자/즐겨찾기, 플랫폼·콘텐츠·제작 분야 필터와 분위기 정렬
- 승인된 프로필·작업 크레딧 양방향 연결
- 이메일 코드 인증 REST 연결 코드, HttpOnly 세션 쿠키와 갱신/로그아웃
- 등록·정정·비공개·크레딧 신청, 본인 신청 상태, 운영자 검토·승인·반려
- 이메일 확인/권한 검사/하루 접수 제한/동일 대상 대기 신청 제한
- 비공개 신청 저장, 공개 필드 제한, 검토 이력, 동시 갱신 재시도
- 로컬 SQLite 기능 검증 모드, 실제 Supabase 서버 어댑터와 RLS 차단 스키마

## 실행

Node 24 이상, 외부 의존성 없음. `npm run dev`는 가상 계정의 로컬 데모, `npm start`는 서버 환경변수 기반 Supabase 모드입니다. `npm test`는 전체 JS 구문 검사와 로직/저장소/HTTP/인증 계약 테스트입니다.

[실제 연결 절차와 사용자 작업](docs/SETUP.md)을 따라 새 전용 DB와 인증을 연결해야 합니다. 기존 프로젝트 DB는 건드리지 않습니다.

실존 인물을 임의 등록하거나 가짜 접수·인증·매출을 표시하지 않습니다. 승인 UI 구현은 실제 채널 소유 확인을 자동으로 수행했다는 뜻이 아닙니다. 공개 전 초기 참여자 확인과 운영 연락처·정보 보관 절차가 필요합니다.
