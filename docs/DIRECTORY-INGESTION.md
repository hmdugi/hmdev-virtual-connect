## 이번 수집 방법
- 공식 스텔라이브 후보 14명을 유지했습니다.
- 공개 2차 자료의 후보 664건을 발견 단계에서 읽고, 기존 이름 10건과 대조하고 같은 채널 중복 4건을 합쳐 신규 650명을 저장했습니다.
- 신규 주 플랫폼 분포: 치지직 350명, SOOP 295명, YouTube 3명, 미확인 2명.
- 이름, 소속 표기, 공개 활동 링크, 장르 태그, 원문 출처와 확인일만 후보 데이터로 남겼습니다. 소개글·이미지·개인 실명·연락처는 수집하지 않았습니다.
- 2차 자료의 자체 확인일은 2026-10-08입니다. 현재 활동 여부를 보장하지 않으며 모든 신규 후보에 secondary_source_needs_verification 사유를 기록했습니다.
- 기본 링크가 없는 항목은 null/빈 배열이며 추측으로 채우지 않았습니다. 개인세의 소속도 공식 확인 전에는 확정하지 않았습니다.
- 활동 중단·졸업으로 표시된 6명도 삭제하지 않았습니다. source_reports_inactive_needs_verification 사유와 원문 상태를 보존했고, 소속 종료와 방송 은퇴를 구분하는 공식 확인이 남았습니다.
- 기존 10명에는 참고 출처만 추가했습니다. 공식 링크·운영자 예외 승인 등 기존 판단은 덮어쓰지 않았습니다.

## 운영 방식
1. 후보를 넓게 모아 먼저 저장합니다.
2. 필수 정보 누락·자료 충돌·제외 사유를 남기고 다음 사람으로 넘어갑니다.
3. 공식 방송 채널/소속사/본인 SNS로 신원과 현재 링크를 대조합니다.
4. 공개 방송 기록으로 활동 경력·누적 방송시간·최근 활동을 검증합니다.
5. 조건을 충족한 후보만 공개용 프로필에 반영합니다. 수집 후보 DB는 서비스 탐색 목록과 별개입니다.

## 자격 기준
- 누적 실제 방송 100시간 이상. 공개 라이브 시작/종료로 확인한 시간의 하한만 합산합니다. 편집 영상 길이나 단순 업로드 수로 대체하지 않습니다.
- 경력 3개월 이상(달력 개월). 공식 데뷔 또는 과거 실제 활동 근거를 사용하며 채널 생성일로 추정하지 않습니다.
- 최근 30일 내 실제 방송 기록을 현재 활동의 초기 기준으로 사용합니다.
- 이름·소속(확인된 개인은 개인)·주 방송 링크·YouTube·SNS·주요 방송 주제.
- 운영자 승인 신인은 경력 기간만 예외입니다. 현재 스텔라이브 4기 시즈키 토아·코가네 랑·하나요 히요리·토키노 메리 4명에 적용했습니다. 100시간과 나머지 요건은 유지합니다.
- 2차 자료 미검증 사유가 남아 있으면 시간과 날짜가 채워져도 자동으로 eligible이 되지 않습니다.

## 남은 검증과 실행 제약
- 신규 650명의 공식 출처 대조, 누락 YouTube/SNS, 개인별 주제 근거, 최근 방송·100시간 확인이 남았습니다.
- 치지직 공개 데이터 호스트가 이 실행 환경에서 시간 초과되어 실제 방송 세션은 아직 0건입니다. 이는 실제 방송시간이 0이라는 뜻이 아닙니다.
- YouTube Data API 수집기는 구현되어 있으나 서버 YOUTUBE_DATA_API_KEY가 연결되지 않았습니다. API 수집 완료로 표시하지 않습니다.
- 후보를 실제 서비스에 공개하지 않았으며 기존 가상 프로필 데모를 실제 데이터로 바꾸지 않았습니다.
- 한 공개 디렉터리 중심의 넓은 발견 목록입니다. 모든 소속사/개인세를 포괄하거나 중복 신원을 전부 정리한 명단이 아닙니다.

## 보관 및 접근
Supabase vc_directory_candidates에 후보를 저장하고 vc_directory_broadcasts에 방송 근거를 별도로 보관합니다. 기존 vc_state 및 다른 앱 데이터는 수정하지 않았습니다. RLS를 활성화하고 anon/authenticated 접근을 차단했으며 서버 권한으로만 접근합니다. GitHub 저장소도 비공개입니다.
