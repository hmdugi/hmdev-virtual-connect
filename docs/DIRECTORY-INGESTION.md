# 버츄링크 실제 프로필 수집 현황
기준: 2026-11-13. 초기 수집이며 국내 전체/모든 플랫폼 수집 완료가 아닙니다.

## 실제 완료
- 스텔라이브 공식 talents 페이지의 공개 프로필 14명 크롤링.
- 14명 모두 이름·소속·주 방송 플랫폼 링크·YouTube 링크·SNS 링크 확보. 개인 실명/연락처/비공개 정보 수집 안 함.
- hmdev Supabase에 vc_directory_candidates 14행 실제 저장, vc_directory_broadcasts 근거 저장 테이블 생성. 기존 vc_state와 다른 앱 데이터는 수정하지 않았습니다.
- 출처 URL과 확인일, 경력 근거와 예외 사유를 저장합니다. 수집 후보와 서비스 공개 프로필은 별개입니다.
- 두 테이블 RLS 활성화, anon/authenticated 읽기·쓰기 차단, service_role 접근만 허용. 보안 어드바이저 경고/오류 없음. 정책 없는 RLS는 서버 전용 의도된 기본 거부(INFO).
- 공식 프로필 수집기와 YouTube Data API 라이브 기록 수집기, 자격 평가기 구현. 전체 자동 테스트 31개 통과.
- 공인된 공개 라이브 시작/종료가 없는 일반 편집 영상/다시보기 재업로드는 방송시간으로 합산하지 않습니다. 중복 기록·동시 송출 시간 중복 합산을 방지합니다.

## 선정 기준
- 누적 실제 방송 100시간 이상. 공개 라이브 기록으로 확인된 시간의 하한을 사용합니다. 자료 부족은 실제 0시간이라는 뜻이 아닙니다.
- 경력 3개월 이상(달력 개월). 공식 데뷔일 또는 과거 활동이 확인된 날짜를 사용합니다. 채널 생성일·자료 첫 수집일을 데뷔일로 취급하지 않습니다.
- 현재 활동: 최근 30일 내 실제 방송 기록. 이는 초기 합리적 기본값이며 사용자 결정으로 변경 가능.
- 필수 프로필: 이름·소속(개인은 확인 후 개인 표기)·방송 링크·YouTube·SNS·주요 방송 주제.
- 추측으로 조건을 채우거나 장기 활동 유명인이라는 이유로 방송시간을 통과시키지 않습니다.

## 신인 예외 — 사용자 추가 결정
확인된 소속사 신인은 경력 3개월 조건을 운영자가 예외 승인할 수 있습니다. '대기업'을 규모 추정만으로 자동 판정하지 않습니다.
현재 승인: 스텔라이브 4기 시즈키 토아·코가네 랑·하나요 히요리·토키노 메리. 공식 데뷔 공지로 소속/신원을 확인하고 career_exception_approved와 사유를 DB에 반영했습니다.
활동기간 예외만 적용합니다. 100시간·현재 활동·필수 정보 요건은 유지합니다. 대상 4명을 제외에서 pending으로 복구했습니다.

## 현재 수치와 남은 작업
- 실제 DB 후보: 14명 (현재 1개 소속사만 수집).
- 경력 예외 승인: 4명.
- 조건 충족 확정/공개 등록: 0명.
- 주로 하는 방송 주제: 아직 미검증. 그룹 전체의 노래·게임 소개를 모든 개인의 주제로 복제하지 않습니다.
- 검증된 방송 세션: 0건. 치지직 공개 데이터 호스트 요청은 이 실행 환경에서 시간 초과, 웹 채널은 텍스트를 반환하지 않았습니다. 제한 우회는 하지 않았습니다.
- YouTube Data API 수집기 실행에는 서버 환경변수 YOUTUBE_DATA_API_KEY가 필요하며 현재 미연결입니다. API 키 없이 실행 성공으로 표시하지 않습니다.
- 현재 서비스 탐색 API에는 이 검토 후보를 연결하지 않았으며 기존 명시적 가상 프로필 데모를 실제 데이터로 바꾸지 않았습니다.
- SOOP·YouTube 중심 개인세·다른 소속사로 범위 확대, 주제별 근거·중복 채널 정리·방송 근거 확보가 남았습니다.

## 재현
Node 24+, 저장소 루트:
1. node scripts/collect-stellive.mjs
2. 공식 원본과 ingest/directory-seed.json의 프로필 링크 대조·경력/주제 근거 검토
3. 서버에 API 키가 설정된 경우 node scripts/collect-youtube-broadcasts.mjs
4. node scripts/evaluate-directory.mjs
5. 검증된 데이터만 서버 권한으로 DB에 반영. 재수집으로 운영자 예외/비공개/정정 결정을 덮어쓰지 않기.

크롤러는 official robots 허용 경로, 제한된 공식 소개 페이지를 읽습니다. 별도 통계 서비스의 데이터베이스를 통째로 복제하지 않습니다. 공식 사이트 소개글/이미지를 대량 복사하지 않고 링크·사실 정보만 수집합니다.
유튜브 수집기는 채널별 업로드 목록 최대 150개를 조회하고 actualStartTime/actualEndTime이 있는 방송만 저장합니다. 이것은 누적 전체 시간의 보장된 총합이 아닌 관측 하한입니다. 기간이 오래된 방송은 공개되지 않을 수 있습니다.
