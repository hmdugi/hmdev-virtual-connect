# 버츄링크: 발견 도구 중심 운영
기준: 2026-11-11. 사용자가 운영 부담을 줄이기 위해 게시판 중심 커뮤니티 대신 발견 도구 모음을 선택했습니다. 이 문서가 이전 COMMUNITY-SPEC.md보다 우선합니다.

## 현재 범위
- 내 취향 방송인/버츄얼 유튜버 찾기: 플랫폼·콘텐츠·분위기 태그 검색·추천 근거.
- 랜덤 방송인 소개: 공개 방송인 중 무작위 선택, 여러 후보가 있으면 직전 결과 제외.
- 취향 조건별 랜덤: 선택한 플랫폼·콘텐츠·분위기를 모두 충족한 공개 프로필만 선택.
- 제작자 탐색·공개 작업 크레딧 연결, 방송 입문/제작 학습 가이드·기기 내 준비 체크.
- 프로필 등록·정정·비공개 요청은 서비스 정보 유지 목적의 기존 검토 흐름으로 유지.

## 제외한 범위
자유/분야별 게시판·댓글·게시물 추천·구인구직 지원·합방 매칭·작업 진행 관리·채팅을 현재 출시 범위에서 제외합니다. 기존 커뮤니티 명세는 과거 확장안으로 보존하며 개발 지시로 사용하지 않습니다. 거래·분쟁 중재를 서비스 기능으로 추가하지 않습니다.

## 자료와 운영
실제 공개 DB는 비어 있습니다. 가상 프로필은 명시적 데모에서만 사용합니다. 실제 채널 확보·등록 동의/공개 근거·태그 출처·갱신일·정정/비공개 처리를 준비해야 합니다.
무작위 소개를 실시간 방송·인기·저평가 판정으로 설명하지 않습니다. 현재 조회수/구독자/실시간 상태 API는 연결하지 않았습니다.
신규 프로필/정정 요청은 한 검토함으로 처리하고 입력 양식·중복 제한·자동 마감/오래된 정보 표시 등으로 관리 부담을 줄입니다. 무인 운영 완료로 표시하지 않습니다.

## 계정
프로젝트별 독립 계정 원칙을 유지합니다. 읽기·검색·취향 찾기·랜덤 소개는 탐색 도구입니다. 개인 계정 저장·프로필 참여 등은 인증 경계가 필요합니다.
기존 로컬 비로그인 즐겨찾기의 로그인 전용 변경과 서비스별 회원 경계 구현은 아직 남아 있습니다. 현재 상태를 완료로 표시하지 않습니다.

## 검증·배포
랜덤 선택 테스트 2개 추가, 총 24개 자동 검사 통과. 새 UI 브라우저 검증·실제 이메일 인증·운영자 지정·자료 확보·상업 프런트 배포는 남아 있습니다. 공개 접수는 중지 상태를 유지합니다. 실기기 검증은 사용자 요청으로 제외했습니다.
